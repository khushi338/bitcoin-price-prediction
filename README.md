# ₿ Bitcoin Price Prediction Dashboard

A Machine Learning-based web application that predicts Bitcoin closing prices
using historical market data and technical indicators.

## Features
- Linear Regression ML model
- Moving Averages (MA7, MA30)
- Actual vs Predicted comparison
- Dark-themed Streamlit UI

## Tech Stack
- Python
- Pandas, Scikit-learn
- Streamlit

## Deployment
Deployed publicly using Streamlit Cloud.
